05 / CLASSIFICATION

HOW THE MODEL DECIDES.

STEP 1 TF-IDF VECTOR 20,000 Dimensions
→
STEP 2 LOGISTIC REGRESSION Linear Boundary (w·x + b)
→
STEP 3 CLASS PROBABILITY Sigmoid σ(z)
→
STEP 4 SENTIMENT Argmax Decision

PROBABILITY ESTIMATION

The trained Logistic Regression classifier receives the TF-IDF feature vector and estimates the probability of each sentiment class.

P(Positive) = 1 / (1 + e^-(w·x + b)) P(Negative) = 1 - P(Positive)
STATISTICAL INFERENCE NOTE: Logistic Regression performs deterministic mathematical classification over n-gram feature frequencies; it does not claim semantic language comprehension like an LLM.

08 / TEXT REPRESENTATION

WHY REPRESENTATION MATTERS.

Machine-learning models cannot directly consume raw text. Words must be mapped into structured numerical vector spaces.

RAW TEXT Unstructured Strings
→
NUMERICAL REPRESENTATION TF-IDF Vector Space
→
MACHINE LEARNING MODEL Logistic Regression

BoW

BASELINE

"Counts word occurrences."

BENCHMARK ACCURACY: 88.26%

Ignores corpus rarity; common words skew classification.

TF-IDF

SELECTED METHOD

"Weights words according to importance."

TUNED ACCURACY: 91.96%

Suppresses non-informative words while elevating distinctive sentiment terms.

N-GRAMS

FEATURE AUGMENTATION

"Captures short sequences of words."

BIGRAM INCLUSION: 20,000 N-Grams

Preserves critical negation semantics such as "not good" or "never recommend".
